# Aether

A solo, top-down action RPG in the visual tradition of 16-bit SNES games. Godot 4.4, GDScript, 320×180 with integer scaling.

## Layout

- `GLOSSARY.md` — the project's vocabulary. Use these terms in code, scenes and docs.
- `scenes/`, `scripts/` — the game. Game rules live in plain scripts with no scene dependencies so they can be tested.
- `tests/` — headless tests. Every `*_tests.gd` file is a suite.
- `art/` — Aseprite source files, one per subject, with named animation tags. `art/aether.gpl` is the shared 32-colour palette every sprite uses. Godot ignores this folder.
- `art/tools/` — the Lua scripts that drew the sprites inside Aseprite, and `export.lua`, which writes the sheets. Re-running a drawing script overwrites hand edits to that sprite.
- `assets/` — PNG sheets and `SpriteFrames` resources exported from `art/`. Do not edit these by hand; repaint the source and re-export.

## Zones

The World (`scenes/world.tscn`) holds the Hero and one Zone at a time. Each Zone is its own scene in `scenes/zones/`, an ordinary tile map you can edit in Godot:

- `Ground` — grass, path, water and thicket. The tile set defines these as terrains, so the editor's terrain tool should pick the right edge tiles (set up by the build script; not yet tried by hand).
- `Things/Props` — trees, rocks and bushes, sorted with the Hero so he walks behind treetops.
- `PuffhopStarts` — one marker per Puffhop.
- `Entrances` — where the Hero leaves and arrives. Each names the Zone it leads to and the matching Entrance there.

The two Zones and the tile set were first generated by `tools/build_zones.gd`. Running it again overwrites them, so once a Zone has been edited by hand, keep editing it in Godot.

## Sound

The sounds in `assets/sounds/` are placeholders synthesised by `tools/make_sounds.py`. To replace one, put a WAV of the same name in that folder. Do not run the script again afterwards, or it overwrites the replacement. Music loudness is `MUSIC_VOLUME_DB` in `scripts/tuning.gd`.

## Run

Open the folder in Godot and press Play, or:

```bash
/Applications/Godot.app/Contents/MacOS/Godot --path .
```

Move with WASD, the arrow keys, or a gamepad's stick or D-pad. Swing with Space, J, or the gamepad's bottom face button.

Numbers that decide how the game feels (speeds, damage, timings) are all in `scripts/tuning.gd`.

## Test

```bash
/Applications/Godot.app/Contents/MacOS/Godot --headless --path . -s tests/run.gd
```

## Re-export art

After changing a file in `art/`, run `art/tools/export.lua` inside Aseprite (File > Scripts, or `aseprite -b --script art/tools/export.lua`).
